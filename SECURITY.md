# Security

## Report a vulnerability

Report a security vulnerability privately through
[GitHub security advisories](https://github.com/cadence-clinical/cadence/security/advisories/new).
Do not open a public issue.

We aim to acknowledge a report within three working days.

## Report a clinical safety concern

A component that could mislead a clinician is a clinical safety concern, not a security
vulnerability. Report it with the
[clinical safety issue template](https://github.com/cadence-clinical/cadence/issues/new?template=clinical-safety.yml).
Never include patient information.

## Supported versions

Cadence is pre-release. Only the latest version receives fixes.
