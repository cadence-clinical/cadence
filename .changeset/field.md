Field, on the Base UI Field and Fieldset, with shadcn's part names. It ties a control to its label, description and error, so no `id`, `htmlFor`, `aria-describedby` or `aria-invalid` is set by hand. The label sits 4px above the control, the error carries an icon and is announced, and a Field inside a Field is one option of a set. Textarea is now rendered through Base UI's Field Control, so a Field can name and describe it.
