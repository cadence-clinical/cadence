Public Sans is the default typeface. `@cadence-clinical/tokens/fonts.css` loads it as a variable font in upright and italic, and `@cadence-clinical/ui/styles.css` and the registry's theme import it for you. Set `--cadence-font-sans` to use your own: a browser downloads a font only when text uses it.
