Typeset: a stylesheet that styles plain HTML inside a `typeset` container, for rendered markdown, patient information and clinical notes. Import `@cadence-clinical/ui/typeset.css`, or add `@cadence/typeset` from the registry. It is adapted from shadcn/typeset and never changes the case of text, so mixed-case (Tall Man) lettering survives. Cadence has no `Text` component: interface text belongs to the component part that shows it.
