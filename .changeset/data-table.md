Data table, on TanStack Table 9, from its own entry point `@cadence-clinical/ui/data-table` with TanStack Table as an optional peer dependency. `DataTable` renders a table you build with `useTable` and `dataTableFeatures`; `DataTableColumnHeader`, `selectionColumn()`, `DataTablePagination` and `DataTableViewOptions` sort, select, page and show columns, with the state in words as well as marks.
