# @cadence-clinical/tokens

## 0.1.0

### Minor Changes

- [`0c3db99`](https://github.com/cadence-clinical/cadence/commit/0c3db9985217b6b0cf700a5cf7740fc8d6d61f1f) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Brands: a preset for the whole page, set with `data-brand`. A brand is an accent seed, light-mode surfaces and text, and fonts. `generateBrandCss` writes its CSS after `assertBrand` has checked every contrast pairing in both modes at both contrast levels. A brand cannot set a status colour, and its surfaces apply in light mode at standard contrast only, so dark mode and more contrast keep Cadence's tested neutrals. `brands.css` ships four example brands, `midnight`, `lagoon`, `cobalt` and `mulberry`, which a page gets only by importing it. Two contrast pairings are new: `input` and `ring` on `popover`, for a control in a dialog or a popover.

- [#23](https://github.com/cadence-clinical/cadence/pull/23) [`6c5ca11`](https://github.com/cadence-clinical/cadence/commit/6c5ca111a86782ecf06fb00344aedad641119171) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Button: `size="icon"` is replaced by an `iconOnly` option that works at every size and variant. It makes the button square and hides the label from sight while keeping it as the accessible name. Button text now steps with `size` (`text-control-sm`, `text-control`, `text-control-lg`), and an icon follows the density (`size-control-icon`: 16px compact, 20px comfortable).

- [#21](https://github.com/cadence-clinical/cadence/pull/21) [`51451ff`](https://github.com/cadence-clinical/cadence/commit/51451ff8819fe442961358efbb12cec909848367) Thanks [@ronaldh46](https://github.com/ronaldh46)! - The density scale now covers content as well as controls. `text-body`, `text-title`, `p-container` and `p-container-sm` follow `data-density`, and Card uses them, so a card's text is the size of the text in a Button inside it at both densities.

- [`770644d`](https://github.com/cadence-clinical/cadence/commit/770644d81329c80a261cff59930c988f4f6b524c) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Dialog, on the Base UI Dialog, with shadcn's part names. It is never taller than the screen, its title wraps and clears the close button, and it opens with a short fade that reduced motion keeps without the growth. The tokens gain `overlay`, a scrim that darkens the page in both modes, and assert muted text on the `popover` surface.

- [#22](https://github.com/cadence-clinical/cadence/pull/22) [`3bb3cbe`](https://github.com/cadence-clinical/cadence/commit/3bb3cbed58f084a47b0766792bf0f8d52c35f76c) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Textarea, Checkbox, Radio group and Switch. The area that takes a click or a tap on a checkbox, a radio or a switch is as large as a control, so it is 44px when the density is comfortable. `size-control-indicator` joins the density scale, and `lucide-react` becomes a dependency of `@cadence-clinical/ui` for the checkbox's tick.

- [#1](https://github.com/cadence-clinical/cadence/pull/1) [`6028504`](https://github.com/cadence-clinical/cadence/commit/60285048db463c04103a654582242445d63c9d11) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Foundations: the Region contract and grade schema in `core`; colour modes, density, curated accents and the accent validator in `tokens`; and Button in `ui`.

- [#20](https://github.com/cadence-clinical/cadence/pull/20) [`9367736`](https://github.com/cadence-clinical/cadence/commit/93677365ed4caf6c321da0693cb6bb16da2eb2dc) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Public Sans is the default typeface. `@cadence-clinical/tokens/fonts.css` loads it as a variable font in upright and italic, and `@cadence-clinical/ui/styles.css` and the registry's theme import it for you. Set `--cadence-font-sans` to use your own: a browser downloads a font only when text uses it.

- [#13](https://github.com/cadence-clinical/cadence/pull/13) [`d121598`](https://github.com/cadence-clinical/cadence/commit/d1215980bc2e0bd0da50a1c84abb041c0c0033c5) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Components can also be installed as source with the shadcn CLI, from the registry at `https://www.cadenceclinical.dev/r/{name}.json`. `@cadence-clinical/tokens` now exports `shadcnCssVars` and `SHADCN_TOKEN_NAMES`: the values the registry's theme writes over a stock shadcn stylesheet.

- [`c63f4c0`](https://github.com/cadence-clinical/cadence/commit/c63f4c06a7ee72347afc30a1251a5595602fc5ba) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Sidebar tokens. `sidebar` is the sidebar's surface. shadcn's seven other sidebar tokens, such as `sidebar-foreground` and `sidebar-primary`, are aliases of the Cadence tokens they correspond to, exported as `SIDEBAR_ALIASES`, so they follow every mode, contrast level, accent and brand. The registry theme carries them. New contrast pairings cover text and the focus ring on `sidebar`, a field on it, and the shown item's bar and focus ring on its fill.

- [#59](https://github.com/cadence-clinical/cadence/pull/59) [`01dd5b0`](https://github.com/cadence-clinical/cadence/commit/01dd5b01801006a3dbbe20e559941e3c155edae5) Thanks [@ronaldh46](https://github.com/ronaldh46)! - A touch device that has not set `data-density` gets a touch default between compact and comfortable: 40px controls, 14px control and body text, 16px titles and 12px padding. It had been comfortable, with 44px controls and 15px text. Set `data-density="comfortable"` for 44px targets. A large control is 44px at the touch default.

- [`53f816d`](https://github.com/cadence-clinical/cadence/commit/53f816d88391c4b6cff2ea46c620bf65c7c75e72) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Typeset: a stylesheet that styles plain HTML inside a `typeset` container, for rendered markdown, patient information and clinical notes. Import `@cadence-clinical/ui/typeset.css`, or add `@cadence/typeset` from the registry. It is adapted from shadcn/typeset and never changes the case of text, so mixed-case (Tall Man) lettering survives. Cadence has no `Text` component: interface text belongs to the component part that shows it.

### Patch Changes

- [#39](https://github.com/cadence-clinical/cadence/pull/39) [`33504d9`](https://github.com/cadence-clinical/cadence/commit/33504d958ab0372248ecdbe944637e080a309183) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Alert, with shadcn's part names and the four statuses. A status carries its fill, its border token, an icon with its own outline and the status in words for a screen reader, so it never rests on colour. `critical` and `warning` are announced at once and the rest politely, the message is at full contrast, and the action drops under the words when the alert is narrow. The tokens now assert the page's text colour on every status fill.

- [#82](https://github.com/cadence-clinical/cadence/pull/82) [`74afdcc`](https://github.com/cadence-clinical/cadence/commit/74afdccd41960e443b7d39154dee125f605ea0d0) Thanks [@ronaldh46](https://github.com/ronaldh46)! - `createAccent` reports a seed that is not a colour in `problems` instead of throwing, and returns the default accent in its place so the result is complete. `checkBrand` reports it the same way. `assertAccent` and `assertBrand` still throw. `Brand`, `AccentDefinition` and `AccentRoles` are read-only.

- [`31d3270`](https://github.com/cadence-clinical/cadence/commit/31d3270c3041e16f3d81518fe6e1c7b6fc05ee4f) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Dropdown menu, on the Base UI Menu, with shadcn's part names except the submenu parts, which are left out. Each item is as high as a control, a checked or chosen item carries a tick, a long item wraps, the menu opens at once, and a label works outside a group as it does in shadcn's blocks. The tokens now assert each status's text colour on the `popover` surface.

- [#19](https://github.com/cadence-clinical/cadence/pull/19) [`d206bb8`](https://github.com/cadence-clinical/cadence/commit/d206bb8a8071a24662e640714ceaea7f486ed9e2) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Label and Input. Both follow the density set on the page. Input keeps a read-only value at full contrast, never fades its boundary or focus ring, and uses 16px text on touch devices so iOS does not zoom. The `input` and `ring` tokens are now contrast-tested against `card` as well as the page.

- [#30](https://github.com/cadence-clinical/cadence/pull/30) [`f1b06dc`](https://github.com/cadence-clinical/cadence/commit/f1b06dce3782f3cbeddce8b42f11858592b37331) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Treat the `light` class on `<html>` as a stated mode. A theme switcher that works by class, such as `next-themes`, states light that way, and the theme ignored it: on a dark operating system, choosing light left every token dark.

- [#36](https://github.com/cadence-clinical/cadence/pull/36) [`ca5a17f`](https://github.com/cadence-clinical/cadence/commit/ca5a17f1a7aeb275bbd41ac553777bb7f261fcfb) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Tabs, on the Base UI Tabs, with shadcn's part names. Tabs that do not fit wrap and are never clipped, the view shows a focus ring when it takes focus, the shown tab is marked by shape as well as colour, and nothing animates. The tokens now assert the focus ring's contrast on the `muted` surface, where a tab's ring sits.

- [`04f92b0`](https://github.com/cadence-clinical/cadence/commit/04f92b0f25bf3a163aeca99b1a1ff4c0cc02996f) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Token names are typed. `resolveTokens` returns `ResolvedTokens`, a record keyed by the new `TokenName` union, so a lookup such as `tokens.critical` is a `string` and a misspelt name is a compile error. `checkContrast` takes the same type, and `ACCENT_NAMES` is a readonly tuple. The generated `theme.css` is unchanged.

- [`7670c7f`](https://github.com/cadence-clinical/cadence/commit/7670c7fcba6fc7473e8c59bedfe1de98626c6756) Thanks [@ronaldh46](https://github.com/ronaldh46)! - Typeset: a small heading (`h5`) and a definition term (`dt`) share one style, and what follows each sits the same distance below. The space a heading owns below it now applies to every element, not only to a paragraph.
