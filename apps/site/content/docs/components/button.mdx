## Usage

```tsx
import { Button } from "@cadence-clinical/ui";

<Button onClick={save}>Save observation</Button>;
```

Button is built on the Base UI [Button](https://base-ui.com/react/components/button) and accepts all of its props.

## Variants

<ComponentPreview>
  <Button variant="primary">Primary</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="destructive">Cease medication</Button>
  <Button variant="link">View history</Button>
</ComponentPreview>

| Variant       | Use                                                                                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `primary`     | The main action in a view. Use one per view.                                                                                                                 |
| `secondary`   | An action of equal weight beside others.                                                                                                                     |
| `outline`     | A lower-emphasis action that still needs a visible boundary.                                                                                                 |
| `ghost`       | Toolbar and inline actions.                                                                                                                                  |
| `destructive` | An action that stops, removes or cannot be undone. It is a solid critical fill so it cannot be overlooked. Ask first in a [Dialog](/docs/components/dialog). |
| `link`        | Navigation in running text.                                                                                                                                  |

Write the label as the action and its object, such as "Cease medication". Avoid "OK" and "Confirm".

## Sizes

<ComponentPreview>
  <Button size="sm">Small</Button>
  <Button size="md">Medium</Button>
  <Button size="lg">Large</Button>
</ComponentPreview>

The `size` prop is relative to the page's [density](/docs/theming#density). A `md` button is 32px high when the density is compact and 44px when it is comfortable. The text steps with the size: 12, 13 and 14px when compact, and 14, 15 and 16px when comfortable.

## Icons

Pass an icon as a child and say which side of the label it is on with `data-icon`. The button sizes the icon and tightens the padding on that side, so do not add a size class or a margin.

```tsx
import { Button } from "@cadence-clinical/ui";
import { ArrowRight, Plus } from "lucide-react";

<Button>
  <Plus data-icon="inline-start" />
  Add observation
</Button>;

<Button variant="outline">
  Next chart
  <ArrowRight data-icon="inline-end" />
</Button>;
```

Cadence uses [Lucide](https://lucide.dev) icons. An icon beside a label is decorative, and Lucide hides it from assistive technology by default. An icon is 16px when the density is compact and 20px when it is comfortable.

### Icon only

Set `iconOnly` and keep the label as the button's text. The button becomes square, the text is hidden from sight, and it is still the button's accessible name, so there is no `aria-label` to forget. `iconOnly` is separate from `size`, so an icon-only button comes in every size and variant.

```tsx
import { Button } from "@cadence-clinical/ui";
import { Printer } from "lucide-react";

<Button variant="outline" size="sm" iconOnly>
  <Printer />
  Print chart
</Button>;
```

## Accessibility

- An icon-only button takes its name from its text, which `iconOnly` hides from sight and keeps for assistive technology.
- The focus ring uses the accent's text role, which holds at least 3:1 against the page in every mode.
- The press animation is removed when the user asks for reduced motion.

## Props

| Prop       | Type                                                                          | Default     |
| ---------- | ----------------------------------------------------------------------------- | ----------- |
| `variant`  | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "link"` | `"primary"` |
| `size`     | `"sm" \| "md" \| "lg"`                                                        | `"md"`      |
| `iconOnly` | `boolean`                                                                     | `false`     |
