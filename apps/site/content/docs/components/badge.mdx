## Usage

```tsx
import { Badge } from "@cadence-clinical/ui";

<Badge variant="outline">Archived</Badge>;
```

Badge follows the shadcn [Badge](https://ui.shadcn.com/docs/components/badge). It renders a `span`, and takes the Base UI [render prop](https://base-ui.com/react/utils/use-render) to become a link.

## Status

<ComponentPreview>
  <Badge variant="critical">Critical</Badge>
  <Badge variant="warning">Warning</Badge>
  <Badge variant="success">Complete</Badge>
  <Badge variant="info">Information</Badge>
</ComponentPreview>

A status badge shows a status it is given. It never works one out: what counts as critical is decided outside Cadence, as [Clinical safety](/docs/clinical-safety) explains.

**The text has to say what the status is.** Colour alone is not read by everyone, so a status badge that holds only a number or a name is not enough. Add the status in words, or an icon with a text alternative.

## What Cadence changes

- **Four status variants**, each with its tinted fill, its text and its border token. The border is what gives an amber fill an edge on a white page. The [status colours](/docs/theming#status-colours) are the same in every theme.
- **Nothing is clipped or cut short.** The shadcn badge has a fixed height, hides its overflow and keeps its text on one line. A badge here has a minimum height and wraps, even a value with nowhere to break, because a badge can hold clinical text.
- **Its text and icon follow the [density](/docs/theming#density)**, and its digits are tabular.
- The `ghost` and `link` variants are not included. Nothing in the plan needs them yet.

## Props

| Prop      | Type                                                                                      | Default       |
| --------- | ----------------------------------------------------------------------------------------- | ------------- |
| `variant` | `"secondary" \| "primary" \| "outline" \| "critical" \| "warning" \| "success" \| "info"` | `"secondary"` |
| `render`  | An element or a function, as in Base UI                                                   | A `span`      |
