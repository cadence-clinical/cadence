## An order with its doses

When it was last given, and the doses in the last 24 hours, including one not given.

```tsx
import { MedicationCard } from "@cadence-clinical/clinical";
import { medicationRecords } from "@cadence-clinical/fhir";

const { records } = medicationRecords(bundle);

<MedicationCard record={records[0]} now={now} timeZone="Australia/Melbourne" />;
```
