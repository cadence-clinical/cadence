```tsx
import { Slash } from "lucide-react";
```

## An ellipsis for the middle on a phone

Below the `md` breakpoint, an ellipsis stands in for the middle pages. It is the trigger of a menu that links to them. Its children are its name, which a screen reader announces: "Earlier pages" here.

      <BreadcrumbSeparator />

        <DropdownMenu>
          <DropdownMenuTrigger className="rounded-sm outline-none hover:text-foreground focus-visible:ring-2 focus-visible:ring-ring">
            <BreadcrumbEllipsis>Earlier pages</BreadcrumbEllipsis>

            <DropdownMenuGroup>
              <DropdownMenuItem render={<a href="#an-ellipsis-for-the-middle-on-a-phone" />}>
                General medicine

                Team

      </BreadcrumbItem>

```tsx
import {
  Breadcrumb,
  BreadcrumbEllipsis,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,

  <BreadcrumbList>

    </BreadcrumbItem>

    <BreadcrumbItem className="hidden md:inline-flex">
      <BreadcrumbLink href="/lists/medicine">General medicine</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator className="hidden md:inline-flex" />
    <BreadcrumbItem className="hidden md:inline-flex">
      <BreadcrumbLink href="/lists/medicine/team">Team</BreadcrumbLink>
    </BreadcrumbItem>
```

## With a router's link

Pass the router's link to `render`, so a page change does not reload the page.

```tsx
import Link from "next/link";

<BreadcrumbItem>
  <BreadcrumbLink render={<Link href="/lists" />}>Lists</BreadcrumbLink>
</BreadcrumbItem>;
```
